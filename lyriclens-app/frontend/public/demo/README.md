# Built-in listening demo

The four-line English text was written for LyricLens. `voice.wav` was generated
locally using the installed Microsoft Zira Desktop synthetic voice. No external
recording or existing song lyrics were used. This is a spoken UI demonstration,
not a singing-quality benchmark or an ASR result.

`transcript.json` records each synthesized line's WAV boundaries. Internal pauses
are retained; timestamps describe passages, not individual words. Audio stays
in the app bundle so the demo needs no model download or backend.

Text:

> Every word can find a place in time.
> Listen to the voice and follow every line.
> Play it back and make the meaning clear.
> Save the words you came here to hear.
